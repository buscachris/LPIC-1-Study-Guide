# My LPIC-1 study notes

I use this space to practice Linux administration at the command line. My starting exercise covers orientation in the shell and interpreting filesystem output.

| Command | What I look for |
| --- | --- |
| `pwd` | The absolute path of my working directory. |
| `ls -a` | The entries in that directory, including names starting with a dot. |
| `df -h .` | The filesystem that contains the current directory, its mount point, and its available space. |

I can repeat these commands in a different directory to see which outputs change when I move within the same filesystem.
